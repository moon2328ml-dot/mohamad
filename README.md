# بازرگانی محمد بهرامی — مدیریت ماشین‌های مرز

نسخه آزمایشی اپ اندروید فارسی، تک‌کاربره و کاملاً آفلاین برای مدیریت ماشین‌های مرزی.

## امکانات نسخه 0.1.0

- ثبت دستی پلاک، راننده، تلفن، نوع بار، صاحب کالا، ترخیص‌کار عراقی، مبدأ، پارکینگ و وزن
- گردش کار: لیست شرکت ← پارکینگ پایین ← باسکول ← پارکینگ بالا ← ورود عراق
- جست‌وجوی سریع و تماس مستقیم با راننده
- ذخیره اطلاعات در SQLite روی خود گوشی
- رابط راست‌چین با تم بنفش
- ساخت خودکار APK با GitHub Actions

حداقل نسخه اندروید: Android 9 (API 28)
